# Inware local development

Open this folder in VS Code and use the **Live Server** extension to serve
`index.html` over HTTP. Workspace settings bind Live Server to
`127.0.0.1:5500`. To open chat directly, use **Open with Live Server** on
`chat.html`.

Use `http://127.0.0.1:5500` (for example,
`http://127.0.0.1:5500/chat.html`); do not open the HTML files directly with
`file://`.
